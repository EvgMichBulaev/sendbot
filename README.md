# Telegram Bot — Отправь мне

Бот на `aiogram3` с поддержкой пересылки сообщений и файлов из групповых чатов, а также хранения файлов с возможностью получения по запросу.

## Возможности

- ✅ Пересылка текстовых сообщений по команде "отправь мне"
- ✅ Пересылка изображений, документов и аудио
- ✅ Сохранение файлов (document, photo, video, audio) в базу данных
- ✅ Получение сохранённых файлов по команде `/files`
- ✅ Поддержка вебхуков и polling-режима
- ✅ Настройка через pydantic-settings
- ✅ Роутеры aiogram для организации обработчиков

## Установка

### 1. Установить зависимости

```bash
pip install -r requirements.txt
```

### 2. Развернуть базу данных PostgreSQL

Бот использует PostgreSQL для хранения метаданных файлов. Для развёртывания базы данных используйте Docker:

```bash
cd postgresql
docker compose up -d
```

База данных будет доступна по адресу: `localhost:5430`

Параметры подключения:
- **User:** tlg
- **Password:** tlg
- **Database:** bot_db
- **Port:** 5430

### 3. Настроить параметры

```bash
cp .env.example .env
```

Откройте `.env` и настройте параметры:

```env
# Токен бота от @BotFather
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz

# URL базы данных (asyncpg для SQLAlchemy async)
DB_URL=postgresql+asyncpg://tlg:tlg@localhost:5430/bot_db

# ADMINS — ID администраторов бота (через запятую)
ADMINS=[123456789]

# URL вебхука (должен быть HTTPS)
WEBHOOK_URL=https://your-domain.com/webhook

# Путь вебхука
WEBHOOK_PATH=/webhook

# Хост и порт для запуска
HOST=0.0.0.0
PORT=8000
```

### 4. Настроить вебхук (опционально)

Если используете вебхук, установите его через бота:

```python
import requests

requests.post(
    f"https://api.telegram.org/bot{BOT_TOKEN}/setWebhook",
    json={"url": "https://your-domain.com/webhook"}
)
```

### 5. Запустить бота

#### Через вебхук:

```bash
python main.py
```

#### Через polling:

```bash
python main_polling.py
```

## Как использовать

### Пересылка сообщений

1. Добавьте бота в групповой чат
2. Дайте боту права администратора (для чтения всех сообщений)
3. В групповом чате:
   - Наведите курсор на любое сообщение (текст, фото, документ, аудио)
   - Нажмите "Ответить" (Reply)
   - Напишите текст: `отправь мне`
   - Отправьте сообщение

Бот перешлёт цитируемое сообщение вам в личные сообщения.

### Сохранение файлов

1. Отправьте боту файл в личных сообщениях (document, photo, video, audio)
2. Бот сохранит файл и пришлёт подтверждение

### Получение сохранённых файлов

1. Отправьте команду `/files`
2. Выберите нужный файл из списка (указан ID пользователя, который его отправил)
3. Бот перешлёт выбранный файл — он останется в хранилище для других пользователей

> 💡 Любой пользователь может получить любой файл из списка — бот позволяет делиться файлами между пользователями.
> 
> ⏰ Файлы хранятся в хранилище 24 часа после отправки, затем автоматически удаляются.

## Архитектура

Проект использует роутеры aiogram для организации кода:

- **`handlers.py`** — содержит фильтры и обработчики сообщений
- **`router.py`** — регистрирует обработчики через декораторы `@router.message()`
- **`config.py`** — настройка бота, диспетчера и параметров через `.env`
- **`dao/model.py`** — модели SQLAlchemy (File для хранения метаданных файлов)
- **`dao/database.py`** — функции работы с базой данных (save_file, get_user_files, delete_file)
- **`main.py`** — запуск через вебхук (FastAPI)
- **`main_polling.py`** — запуск через polling (простой режим)

## Развёртывание на VPS (вебхук)

Для развёртывания на VPS используется автоматизированный скрипт `deploy.sh`:

### Требования
- Чистый Ubuntu/Debian сервер
- Домен `{YOUR_DOMAIN}` указывает на IP сервера (A record)
- Порты 80 и 443 открыты
- Пользователь с sudo правами

### Запуск

```bash
# Скопируйте скрипт на сервер
sudo scp deploy.sh user@vm.ebul.online:/tmp/

# Запустите на сервере
sudo bash /tmp/deploy.sh
```

Скрипт автоматически:
1. Установит все зависимости (nginx, docker, python3, certbot)
2. Развернёт PostgreSQL через Docker Compose
3. Клонирует репозиторий в `/srv/sendbot`
4. Создаст виртуальное окружение и установит зависимости
5. Применит миграции Alembic
6. Настроит Nginx как reverse proxy
7. Получит SSL-сертификат через Let's Encrypt
8. Запустит бота через systemd

После запуска не забудьте отредактировать `/srv/sendbot/.env.production` и указать `BOT_TOKEN` и `ADMINS`.

### Полезные команды

```bash
# Просмотр логов бота
journalctl -u sendbot -f

# Перезапуск бота
systemctl restart sendbot

# Просмотр логов PostgreSQL
docker logs postgres_container -f

# Тест Nginx
nginx -t
```
