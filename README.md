# Telegram Bot — Отправь мне цитату

Бот на `aiogram3`, который в групповых чатах получает цитированные сообщения с командой **"отправь мне"** и пересылает их в личные сообщения.

## Возможности

- ✅ Поддержка текстовых сообщений
- ✅ Поддержка изображений (фото)
- ✅ Поддержка документов (files)
- ✅ Поддержка аудио (музыка, голосовые)

## Установка

### 1. Клонировать репозиторий

```bash
git clone <repository_url>
cd sendbot
```

### 2. Установить зависимости

```bash
pip install -r requirements.txt
```

### 3. Настроить токен бота

```bash
cp .env.example .env
```

Откройте `.env` и вставьте токен, полученный от [@BotFather](https://t.me/BotFather):

```
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
```

### 4. Запустить бота

```bash
python main.py
```

## Как использовать

1. Добавьте бота в групповой чат
2. Дайте боту права администратора (для чтения всех сообщений)
3. В групповом чате:
   - Наведите курсор на любое сообщение (текст, фото, документ, аудио)
   - Нажмите "Ответить" (Reply)
   - Напишите текст: `отправь мне`
   - Отправьте сообщение

Бот перешлёт цитируемое сообщение вам в личные сообщения.

## Требования

- Python 3.10+
- Токен Telegram бота
