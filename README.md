# Telegram Bot — Отправь мне цитату

Бот на `aiogram3` с вебхуками, который в групповых чатах получает цитированные сообщения с командой **"отправь мне"** и пересылает их в личные сообщения.

## Возможности

- ✅ Поддержка текстовых сообщений
- ✅ Поддержка изображений (фото)
- ✅ Поддержка документов (files)
- ✅ Поддержка аудио (музыка, голосовые)
- ✅ Вебхуки вместо поллинга
- ✅ Настройка через pydantic-settings

## Установка

### 1. Установить зависимости

```bash
pip install -r requirements.txt
```

### 2. Настроить параметры

```bash
cp .env.example .env
```

Откройте `.env` и настройте параметры:

```env
# Токен бота от @BotFather
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz

# URL вебхука (должен быть HTTPS)
WEBHOOK_URL=https://your-domain.com/webhook

# Путь вебхука
WEBHOOK_PATH=/webhook

# Хост и порт для запуска
HOST=0.0.0.0
PORT=8000
```

### 3. Настроить вебхук

Установите вебхук через бота:

```python
import requests

requests.post(
    f"https://api.telegram.org/bot{BOT_TOKEN}/setWebhook",
    json={"url": "https://your-domain.com/webhook"}
)
```

### 4. Запустить бота

```bash
python main.py
```

## Как использовать

1. Добавьте бота в групповой чат
2. Дайте боту права администратора (для чтения всех сообщений)
3. В групповом чате:
   - Наведите курсор на любое сообщение (текст, фото, документ, аудио)
   - Нажмите "Ответить" (Reply)
   - Напишите текст: `отправь мне`
   - Отправьте сообщение

Бот перешлёт цитируемое сообщение вам в личные сообщения.

## Требования

- Python 3.10+
- Токен Telegram бота
- Домен с SSL-сертификатом (для вебхуков)
